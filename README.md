# YourTurn — BETA

YourTurn is a UK-focused job discovery platform designed to search beyond traditional job aggregators.

## BETA roadmap

1. Design / Structure
2. Theme / Comfort
3. Technical
4. Databases
5. Test
6. Publish

The current BETA starts with the welcome experience. Account setup, CV analysis, job search, integrations and data sources will be added in later stages.
